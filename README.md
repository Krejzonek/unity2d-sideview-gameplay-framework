# Polski

## O projekcie

**Unity2D.SideView.GameplayFramework** to fundament rozgrywki przeznaczony do tworzenia gier 2D z widokiem z boku (Side-View) w silniku Unity.

Projekt udostępnia gotowe systemy rozgrywki, które można wykorzystać, rozwijać i dostosowywać do własnych projektów. Nie jest to ukończona gra ani osobny silnik. Jego celem jest dostarczenie podstawowej logiki i mechanik, aby twórcy mogli skupić się na własnej zawartości i oprawie wizualnej.

Projekt nie zawiera kompletnej oprawy graficznej, animacji, poziomów ani dźwięków. Elementy wizualne służą przede wszystkim do testowania i prezentowania mechanik.

## Informacje o projekcie

- **Silnik:** Unity
- **Wersja:** Unity 2022.3.61f1
- **Język programowania:** C#
- **Typ:** 2D Side-View Gameplay Framework
- **Tryb:** Single-player PvE
- **System drużyny:** opcjonalny
- **Sterowanie:** klawiatura i mysz, kontrolery oraz urządzenia mobilne
- **Autor:** Krejzonek

## Funkcjonalności

Projekt zawiera między innymi:

- system zarządzania postaciami i drużyną;
- system sterowania postacią;
- obsługę kontrolerów i urządzeń mobilnych;
- walkę wręcz i dystansową;
- system broni, pocisków i magii;
- statystyki postaci i efekty statusu;
- klasy postaci, poziomy i doświadczenie;
- umiejętności aktywne i pasywne;
- przeciwników i system AI;
- różne typy przeciwników i zachowania bossów;
- ekwipunek i wyposażenie;
- przedmioty, rzadkość i bonusy statystyk;
- system łupów i skrzyń;
- składniki, receptury i crafting;
- NPC, dialogi i handel;
- generowanie i zarządzanie pomieszczeniami;
- system checkpointów;
- zapisywanie i odczytywanie stanu gry;
- menu, HUD i interfejs użytkownika.

Nie wszystkie systemy muszą być wykorzystywane w każdym projekcie. Framework można dostosowywać do własnych potrzeb.

# English

## About

**Unity2D.SideView.GameplayFramework** is a gameplay foundation for creating 2D side-view games using the Unity engine.

The project provides reusable gameplay systems that developers can use, extend, and customize for their own projects. It is not a finished game or a standalone engine. Its purpose is to provide core gameplay logic and mechanics so developers can focus on creating their own content and visual presentation.

The project does not include a complete art style, animations, levels, or audio. Visual elements are primarily intended for testing and demonstrating gameplay systems.

## Project Information

- **Engine:** Unity
- **Version:** Unity 2022.3.61f1
- **Programming Language:** C#
- **Type:** 2D Side-View Gameplay Framework
- **Game Mode:** Single-player PvE
- **Team System:** Optional
- **Input:** Keyboard and mouse, game controllers, and mobile devices
- **Author:** Krejzonek

## Features

The project includes, among other things:

- character and team management;
- character controller system;
- game controller and mobile input support;
- melee and ranged combat;
- weapon, projectile, and magic systems;
- character statistics and status effects;
- character classes, levels, and experience;
- active and passive skills;
- enemies and AI systems;
- different enemy types and boss behaviours;
- inventory and equipment;
- items, rarity, and stat bonuses;
- loot and chest systems;
- ingredients, recipes, and crafting;
- NPCs, dialogue, and trading;
- room generation and management;
- checkpoint system;
- game-state saving and loading;
- menus, HUD, and user interface.

Not every system is required for every project. The framework can be adapted to individual needs.

## Requirements

- Unity 2022.3.61f1;
- packages required by the project;
- a development environment supporting C# and Unity.

## Getting Started

1. Clone the repository.
2. Open the project in Unity Hub.
3. Use Unity version 2022.3.61f1.
4. Wait for assets to import and dependencies to resolve.
5. Open a scene from `Assets/Scenes`.
6. Run the project and test the systems.
7. Add your own graphics, animations, levels, audio, and other content.

## Who Is This For?

This framework is intended for developers who want to create their own 2D side-view game and need a reusable foundation for gameplay mechanics.

You can use it as a starting point for your own project, modify existing systems, and add new functionality.

## Project Status

This project is an evolving gameplay foundation. Some features may require further improvements, testing, or customization. Not all systems are guaranteed to be free of bugs.
